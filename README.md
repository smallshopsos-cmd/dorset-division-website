# Dorset Division

Complete current Dorset Division website. Serve the `dist` directory as the static website (no build step).

Includes six main pages, two case studies, seven policy pages, all assets, cookie preferences and Burt. The Services & Prices page uses `contact.html`.

Burt's frontend is installed; live AI answers require a Cloudflare Worker endpoint. Worker source is in `integrations/burt/cloudflare-worker.mjs`.
